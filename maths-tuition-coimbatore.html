Maths tuition by class

Classes 1–5: number sense and confidence

Place value, the four operations, fractions, measurement and word problems — built with regular short practice so basics become automatic.

Classes 6–8: the bridge to algebra

Integers, ratios, algebraic expressions, linear equations and geometry. This is where many children start to struggle; we fix gaps before they grow.

Classes 9–10: board-exam maths

Full syllabus coverage for CBSE, ICSE and State Board, chapter tests, previous-year question practice and step-wise answer writing for full marks.

Classes 11–12: higher secondary maths

Calculus, algebra, vectors, probability and statistics — with focused practice for board exams and a strong base for JEE / competitive exams.
